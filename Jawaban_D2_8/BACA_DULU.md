# D2.8 · Urutan pengerjaan

1. Ekstrak ZIP, lalu buka folder Jawaban_D2_8 di VS Code.
2. Baca pembelaan pull-up di reviews/final_defense.md. Siapkan catatan prediksi pribadi yang sudah dibuat sebelum uji beserta data yang mengoreksinya.
3. Jalankan perintah PowerShell dalam dokumen itu. Folder bukti/run_acuan berisi hasil simulasi yang dibuat saat penyusunan paket. Setiap eksekusi pada laptop membuat folder run_pribadi tersendiri, lengkap dengan salinan input dan log.
4. Gunakan grafik pribadi untuk presentasi enam menit. Catat lokasi file pada reviews/final_defense.md dan scorecard.csv. Siapkan lima jawaban untuk empat menit tanya jawab serta audit acak sumber, perintah dan parameter.
5. Penguji mencatat bukti, skor dan gate. Cocokkan status D2.7 dengan hasil reviewer terbaru. Lengkapi final_signoff.md ketika bukti tersedia.
6. Setelah nilai dikunci, isi judul, edisi, bab dan halaman buku Analog untuk sepuluh pertanyaan hari ketiga. Simpan perubahan, lalu ZIP kembali folder Jawaban_D2_8 beserta hasil pribadi.
